Bento Grid Stress Test

Renders a dense grid of 400 boxes over 16 procedurally generated backgrounds, each running an ipax-backdrop instance. Designed to stress-test the engine against high-demand layouts (e.g., dense newspaper indexes with backdrop titles over thumbnails).

Performance mitigations

  • Viewport Culling: IntersectionObserver suspends rendering for off-screen layers.
  • Bounded DOM Polling: Caps elementsFromPoint() queries to viewport area limits, preventing main thread locks on oversized containers.
  • CSSOM Isolation: Scoped CSS custom properties prevent global style recalculation when manipulating sliders.
  • Event Debouncing: Coalesces simultaneous async texture loads into single invalidation ticks.

Note: The harmonic palettes used in these textures preview the upcoming IPAX Color System Builder.
